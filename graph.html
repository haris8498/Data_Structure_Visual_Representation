Graph

Definition

A Graph is a non-linear data structure consisting of vertices (nodes) and edges (connections). Graphs can be directed or undirected, weighted or unweighted.


Types: Directed, Undirected, Weighted, Cyclic, Acyclic

Adjacency List Code

class Graph {
    int V;
    list *adj;
public:
    Graph(int V) {
        this->V = V;
        adj = new list[V];
    }
    
    void addEdge(int u, int v) {
        adj[u].push_back(v);
        adj[v].push_back(u); // Undirected
    }
    
    void BFS(int s) {
        bool visited[V] = {false};
        queue q;
        visited[s] = true;
        q.push(s);
        while (!q.empty()) {
            s = q.front();
            cout << s << " ";
            q.pop();
            for (auto i : adj[s]) {
                if (!visited[i]) {
                    visited[i] = true;
                    q.push(i);
                }
            }
        }
    }
};
