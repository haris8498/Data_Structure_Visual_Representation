Binary Search

Definition

Binary Search looks for a specific element in a sorted array by repeatedly dividing the search interval in half.


Time Complexity: O(log n)

Visual Implementation

Click "Start Search" to find number 60

Code

int binarySearch(int arr[], int l, int r, int x) {
    while (l <= r) {
        int m = l + (r - l) / 2;
        if (arr[m] == x) return m;
        if (arr[m] < x) l = m + 1;
        else r = m - 1;
    }
    return -1;
}
