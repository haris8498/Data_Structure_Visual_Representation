Linear Search

Definition

Linear Search is a simple searching algorithm that checks every element in the array sequentially until the target is found or the end is reached.


Time Complexity: O(n) | Space Complexity: O(1)

Visual Implementation

Click "Start Search" to find number 75

Code

int linearSearch(int arr[], int n, int x) {
    for (int i = 0; i < n; i++) {
        if (arr[i] == x)
            return i;
    }
    return -1;
}
