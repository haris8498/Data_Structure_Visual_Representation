Binary Tree

Definition

A Binary Tree is a hierarchical data structure where each node has at most two children, referred to as the left child and the right child.


Properties: Root, Parent, Children, Leaf nodes, Height, Depth

Binary Tree Structure

Structure Code

struct Node {
    int data;
    Node *left, *right;
    Node(int val) {
        data = val;
        left = right = nullptr;
    }
};

void inorder(Node* root) {
    if (root == nullptr) return;
    inorder(root->left);
    cout << root->data << " ";
    inorder(root->right);
}
