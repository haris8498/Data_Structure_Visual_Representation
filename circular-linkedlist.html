Circular Linked List

Definition

A Circular Linked List is a variation of linked list where the last node points back to the first node, forming a circle.


Advantage: Any node can be the starting point. Useful for circular queues and round-robin scheduling.

Structure Code

struct Node {
    int data;
    Node* next;
};

void insertEnd(Node*& head, int data) {
    Node* newNode = new Node();
    newNode->data = data;
    if (!head) {
        head = newNode;
        newNode->next = head; // Points to itself
        return;
    }
    Node* temp = head;
    while (temp->next != head) temp = temp->next;
    temp->next = newNode;
    newNode->next = head; // Circular link
}
